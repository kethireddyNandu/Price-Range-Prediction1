PRICE RANGE PREDICTION

##  Project Overview
This project predicts the price range of restaurants using Machine Learning and Deep Learning techniques. The model is trained on restaurant features such as location, ratings, online delivery, table booking, votes, cuisines, and other attributes to classify restaurants into different price categories.

---

##  Features
- Data preprocessing and cleaning
- Feature engineering
- Data visualization
- Train-test split
- Feature scaling
- Deep Neural Network (PyTorch)
- Model evaluation
- Price range prediction for new restaurant data

##  How to Run

1. Clone the repository

```bash
git clone https://github.com/kethireddyNandu/Price-Range-Prediction.git
```

2. Navigate to the project

```bash
cd Price-Range-Prediction
```

3. Install required libraries

```bash
pip install pandas numpy matplotlib seaborn scikit-learn torch
```

4. Open the notebook

```bash
jupyter notebook Price_Range_Prediction.ipynb
```

or upload it to **Google Colab** and run all cells.
